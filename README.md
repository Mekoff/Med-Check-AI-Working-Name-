# Med-Check AI (Working Title)
## 📋 Project Charter (The Authorization)

### 👁️ Vision Statement
To eliminate preventable adverse drug events (ADEs) by providing a mobile-first, AI-driven pharmacovigilance tool for patients and clinicians.

---

### 🎯 Core Objective
Develop a cross-platform MVP (Minimum Viable Product) capable of scanning medications via OCR to identify drug-drug/substance interactions and side effects.

* **Executive Sponsor:** Dr. Felix Chukwuemeka Offor (MD, MBA)

---

### 🔍 High-Level Scope

#### ✅ In-Scope
* OCR medication scanning
* RxNav API integration
* Interaction flagging & alerting
* Patient-friendly side effect summaries

#### ❌ Out-of-Scope
* Direct electronic prescribing (e-Rx)
* Diagnosing new clinical conditions
* Pediatric-specific dosing protocols
